# Classes

## Rules

* We treat classrooms as root orgs, each user has different role with classes inside the same parent org. If the user is the owner of Computer Networks inside BCA, Sem1, section A. He cannot access the other OS class at all. There will be a owner of the class and we can have several teacher with Class Memberships. The ownerhip will be transferrable to the teacher that are already part of the classroom. ViewChildOrgs will be changed.

* The owner and admin of the org can access the class even if they are not the owner of the class.
